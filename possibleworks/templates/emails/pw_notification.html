{# Possibleworks branded email shell. Two things this comment must never contain, both learned the hard way: An angle-bracketed tag name. Editors do not treat Jinja comment delimiters as comments, so a literal style tag here opens an embedded CSS region that runs to the end of the file and buries it in phantom errors. A closing comment delimiter, even inside backticks. Jinja ends the comment at the first one it sees, and everything after it renders into the email. Starts at a div, never an html or body tag: Frappe drops whatever you hand `frappe.sendmail` into a paragraph (see templates/emails/standard.html), and a block-level document tag nested inside a paragraph is invalid -- every mail client recovers from it differently. Every rule is inline. Gmail strips embedded stylesheets outright, and Frappe's own CSS inliner only knows about its own classes, not ours. All human-readable text goes through `| e`. Frappe's Jinja environment runs with autoescape off, and some of these values (an applicant's own name) are user-supplied. URLs are emitted raw and are trusted by contract -- callers build them, never users -- because escaping an ampersand inside a signed link is a good way to break a signature. #}
